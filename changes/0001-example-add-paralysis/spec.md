# 要件: まひ状態 (Paralysis)
まひ状態のポケモンは攻撃・逃げができず、ターン終了時に回復する。

### S0001_01 まひ付与
- GIVEN バトル場のポケモンがまひでない
- WHEN まひを与える効果が解決される
- THEN そのポケモンはまひ状態になる

### S0001_02 まひ中は攻撃・逃げ不可
- GIVEN バトル場のポケモンがまひ状態
- WHEN そのポケモンで攻撃または逃げを試みる
- THEN その行動は合法手に含まれない

### S0001_03 ターン終了時に回復
- GIVEN まひ状態のポケモンがバトル場にいる
- WHEN そのプレイヤーのターンが終了する
- THEN まひ状態は解除される

### S0001_04 ベンチのポケモンにはまひを付与できない
- GIVEN ベンチにいるポケモン
- WHEN そのポケモンにまひを与える効果が解決される
- THEN まひは付与されず、状態は変化しない

### S0001_05 既にまひ状態への再付与 [境界]
- GIVEN 既にまひ状態のポケモン
- WHEN さらにまひを与える
- THEN 状態は変化せず、カウントもリセットされない
